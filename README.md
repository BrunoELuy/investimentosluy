# Invest Tracker

Faça um app para eu acessar no celular que tenha banco de dados local. Esse será um app de gerenciamento de investimentos. Permitindo definir entre LCA e CDB, podendo ser % da CDI, IPCA Taxa fixa, tempo de duração de investimento. Vale lembrar que deve ter as regras de resgate de IR e IOF para os CDB's, além de o app ter que atualizar automaticamente a taxa atual de CDB realista toda vez que for aberto com internet.

Apresente os investimentos, podendo filtar pelo tipo (LCA/CDB) ou algum específico, ou todos, apresente dashboards de evolução % líquida e bruta de cada investimentos, além do rendimento bruto e líquido
